## 已交付功能

### 图片输入

- JPG、PNG、WebP 文件选择、页面拖拽和剪贴板图片粘贴。
- HTTP/HTTPS 图片 URL 输入；使用标准 CORS 请求，失败时明确提示下载后上传，不使用绕过代理。
- 浏览器解码时应用 EXIF 方向；文件上限 20 MB，单边上限 12,000 px，总像素上限 40 MP。
- 用户图片只在浏览器内处理，默认不上传服务器或第三方服务。

### 图片转换

- 29×29、52×52 以及自定义宽高；转换结果矩阵严格等于目标尺寸。
- 原图比例、完整显示并留白、居中裁剪铺满三种构图方式。
- 卡通/写实两种采样 profile、色数限制、背景容差、透明背景、去杂点和相近颜色整理。
- MARD 221/291 色卡；CIEDE2000（默认）、CIE76/Lab、加权 RGB 三种匹配算法。
- CIEDE2000 使用预计算 Lab 色卡；候选色阶段按每格平均色统计，避免 52×52 转换产生数千万次重复 Lab 运算。

### 编辑与统计

- 复用上游 Canvas 编辑器：画笔、橡皮、填充、吸管、换色、移动、复制、粘贴、镜像、形状、文字、图层、撤销/重做、缩放和平移。
- 任意单格修改后，用量和总颗数立即更新；撤销后同步恢复。
- 支持透明空白格、网格、坐标、色号显示、分层统计和总用量统计。

### 导出与工程文件

- 图纸 PNG/PDF：网格、坐标、色号、图例和分层输出沿用成熟上游实现。
- 纯像素 PNG：每格一像素，空白格 alpha=0；支持 1×、4×、8×最近邻整数倍复制。
- CSV 和 XLSX 材料清单；CSV 包含品牌、色号、名称、HEX、数量和预计包数。
- JSON 工程文件使用 `bead-studio-project` + `schemaVersion: 2.0.0` 封装；兼容读取旧版裸项目 JSON。
- 52×52 仅作为智能板测试预设，未完成厂商 App 实测前不标记兼容。

## 发布步骤

1. 将 `bead-studio-web` 推送到用户拥有写权限的 GitHub 仓库 `main` 分支。
2. 在仓库 `Settings → Pages` 中选择 `GitHub Actions`。
3. 等待 `CI` 和 `Deploy to GitHub Pages` 两个工作流成功。
4. 用真实厂商 App 导入 52×52、1×纯像素 PNG；记录 App 版本、导入尺寸、透明处理和色彩是否保持。

当前唯一发布阻塞项是缺少目标远程仓库及其推送权限。该阻塞不影响本地 V1 功能完整性，但在完成授权前不能提供公开网址。
